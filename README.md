# Cost Per Lease

The open research initiative for the new economics of occupancy.

Cost Per Lease gives asset owners, operators, and the next generation of real
estate leaders a shared framework for measuring what occupancy costs and
optimizing what it earns.

## Local development

```bash
npm install
npm run dev
```

## Production builds

`npm run build` validates the Vinext/Sites build. `npm run build:pages` creates
the static export used by GitHub Pages.

The public site is designed for `https://costperlease.com`.

## Research program

The working materials for the Founding CPL Benchmark Cohort live in
[`research/`](research/README.md). They include the draft CPL Standard, cohort
operating and privacy protocols, calculation rules, data templates, assessment
templates, and recruitment materials.

All cohort materials are pre-launch drafts. Legal terms require review by
qualified counsel, and benchmark claims must pass the publication gates in the
research protocol before release.
