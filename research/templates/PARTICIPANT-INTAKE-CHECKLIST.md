# Participant Intake Checklist

**Participant code:** `[FIRM-XX]`
**Data owner:** `[NAME / ROLE]`
**Target submission:** `[DATE]`

## Before transfer

- [ ] Contribution agreement executed by both parties.
- [ ] Eligible properties confirmed as stabilized conventional market-rate multifamily.
- [ ] Firm and property codes issued through a separate channel.
- [ ] Data owner and finance reconciliation contact named.
- [ ] Eight quarters requested; available history documented.
- [ ] Data dictionary reviewed.
- [ ] No resident, applicant, employee, unit-level, contact, or raw CRM data included.
- [ ] Secure transfer account uses multi-factor authentication.
- [ ] Participant understands aggregate-use and destruction terms.

## Submission preparation

- [ ] One row per property-quarter.
- [ ] Blank means unavailable; zero means confirmed none.
- [ ] Calendar quarter-end dates used.
- [ ] New leases exclude transfers and 30-day cancellations.
- [ ] Renewals exclude passive month-to-month continuations.
- [ ] Concessions use face value at lease execution.
- [ ] Vacancy excludes bad debt and delinquency.
- [ ] Turnover/make-ready excludes capital improvements.
- [ ] Central allocations include method, rate, and source note.
- [ ] Costs are assigned to one canonical input category only.
- [ ] Revenue, NOI, vacancy, concessions, and turnover totals reconciled.
- [ ] Workbook contains no hidden sheets, external links, macros, or embedded files.

## Cost Per Lease receipt

- [ ] Upload recorded without property values in administrative tracker.
- [ ] File scanned for prohibited data before analysis.
- [ ] Hidden sheets, links, and file properties reviewed.
- [ ] Submission copied to read-only restricted source location.
- [ ] Identity mapping remains separate.
- [ ] Intake validation run.
- [ ] Discrepancy list sent through approved secure channel.
- [ ] Validation interview scheduled.
