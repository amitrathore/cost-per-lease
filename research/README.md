# Cost Per Lease Research Program

This directory is the operating package for the Founding CPL Benchmark Cohort.
It turns the public Cost Per Lease thesis into a controlled, no-code research
program for stabilized, conventional, market-rate multifamily properties.

## Source of truth

Use these documents in this order:

1. [`standard/CPL-STANDARD-v0.1-DRAFT.md`](standard/CPL-STANDARD-v0.1-DRAFT.md)
   defines the measures and reporting rules.
2. [`methodology/CALCULATION-SPEC.md`](methodology/CALCULATION-SPEC.md) defines
   exact calculations, allocations, and aggregation.
3. [`methodology/QUALITY-CONTROLS.md`](methodology/QUALITY-CONTROLS.md) defines
   validation checks and publication gates.
4. [`cohort/FOUNDING-COHORT-PLAYBOOK.md`](cohort/FOUNDING-COHORT-PLAYBOOK.md)
   defines the 12-week operating process.
5. [`cohort/DATA-HANDLING-AND-DESTRUCTION-PROTOCOL.md`](cohort/DATA-HANDLING-AND-DESTRUCTION-PROTOCOL.md)
   defines how restricted data is handled and destroyed.

The `templates/` directory contains the participant intake schema, private
assessment and public brief templates, validation interview guide, destruction
certificate, and operational checklists. `cohort/` also contains recruitment
copy and a draft contribution agreement for counsel.

## Status

- Standard: **Draft v0.1**
- Cohort: **Pre-recruitment**
- Target: **10 firms / 50 properties / up to 8 quarters**
- Public benchmark gate: **5 firms and 25 valid properties minimum**
- Data posture: **restricted source data destroyed; qualifying aggregates only retained**

## Hard boundaries

- Do not collect resident, applicant, employee, unit-level, contact, or raw CRM
  data.
- Do not send participant workbooks by ordinary email.
- Do not provide participant data or property-level derived data to Leaser AI.
- Do not publish a cohort cell with fewer than five firms or ten properties, or
  where one firm contributes more than 25 percent of the cell.
- Do not call the output an industry benchmark if the publication gate is not
  met. Call it a methodology pilot.
- Do not use the legal draft without qualified counsel review.

## External actions not completed in this repository

The operating package is ready for these owner-led steps:

- Form or designate the independent Cost Per Lease legal entity.
- Retain privacy/data and trademark counsel.
- Clear and file appropriate marks.
- Select an access-controlled encrypted file-transfer/data-room provider.
- Recruit and contract with cohort participants.
- Appoint one multifamily operator and one finance/accounting reviewer.

## Version control

Any change to a definition, formula, allocation rule, or suppression threshold
must update the version history in the draft standard and the calculation spec.
Never silently revise a metric after participant intake begins.
